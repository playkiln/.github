# Security policy

Do not report vulnerabilities through a public issue or discussion.

Use **Report a vulnerability** on the Security tab of the affected repository. Include the affected component, reproduction steps, impact, and any suggested remediation. Avoid accessing data that is not yours, disrupting service, or publishing details before a coordinated resolution.

Playkiln will acknowledge actionable reports, investigate them according to severity, and coordinate disclosure when appropriate. Only currently supported releases are eligible for security fixes.
