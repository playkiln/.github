# Security policy

Do not report vulnerabilities through a public issue or discussion.

**For the Playkiln platform** — playkiln.com, the games it serves, the API, or
the CLI — email **security@playkiln.com**. Playkiln runs code that other people
upload, so platform reports are the ones that matter most and there is a
dedicated address for them. The same address is published at
[playkiln.com/.well-known/security.txt](https://playkiln.com/.well-known/security.txt).

**For a bug in a specific repository in this organization**, use **Report a
vulnerability** on that repository's Security tab. Private vulnerability
reporting is enabled on every public repository here.

Either way, include the affected component, reproduction steps, impact, and any
suggested remediation. Avoid accessing data that is not yours, disrupting
service, or publishing details before a coordinated resolution.

Playkiln will acknowledge actionable reports, investigate them according to
severity, and coordinate disclosure when appropriate. Only currently supported
releases are eligible for security fixes.
