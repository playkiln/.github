# Contributing to Playkiln

Playkiln is currently in private development. Public repositories accept focused documentation, packaging, and starter corrections once their corresponding artifacts are released.

Before opening a substantial pull request, open an issue describing the user problem, proposed boundary, compatibility effect, and validation plan. Keep changes narrowly scoped, add automated evidence where behavior changes, and update the authoritative documentation with any public contract change.

By participating, you agree to follow the organization code of conduct and security policy.
