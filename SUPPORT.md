# Support

Use a repository issue for reproducible bugs and documentation defects. Include
the affected version, operating system, expected behavior, actual behavior, and
the smallest useful reproduction.

For anything that is not a repository bug — an account question, a game that
will not load, or feedback on the platform — email **hello@playkiln.com**.

For vulnerabilities, do not open an issue. Email **security@playkiln.com** for
the platform, or use private vulnerability reporting from the affected
repository's Security tab for a repository bug. Never include credentials or
private account data in a public issue.
