# Playkiln

Playkiln is an AI-first creator network for small browser games.

Builders use a compatible AI assistant or the Playkiln CLI to shape, build,
preview, validate, and publish a game. Players discover those games through the
Board, play immediately, achieve, follow builders, and return.

```text
build → publish → Discover → Board → play → achieve → follow → return
```

The platform is under active development, and the canonical product repository
is private. Public repositories here carry the parts builders use directly.

- Product: [playkiln.com](https://playkiln.com)
- About and contact: [playkiln.com/about](https://playkiln.com/about)
- General: hello@playkiln.com
- Security: security@playkiln.com, or private vulnerability reporting on the
  affected repository
