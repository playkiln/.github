# Playkiln

Playkiln is an AI-first creator network for small browser games.

Builders use a compatible AI assistant or the Playkiln CLI to shape, build, preview, validate, and publish a game. Players discover those games through the Board, play immediately, achieve, follow builders, and return.

```text
build → publish → Discover → Board → play → achieve → follow → return
```

The platform is under active development. The canonical product repository remains private until the public development and security policies are ready; public CLI distribution and starter projects will appear here as their release milestones complete.

- Product: [playkiln.com](https://playkiln.com) (DNS cutover in progress)
- Security: use private vulnerability reporting in the affected repository
